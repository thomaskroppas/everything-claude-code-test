# «Отсечка» — журнал об автомобилях

Статический блог на русском: 100 статей в восьми рубриках, собственный дизайн, сборка без зависимостей.

## Что внутри

| Путь | Что это |
|---|---|
| `content/articles/*.md` | 100 статей: frontmatter (`title`, `slug`, `category`, `date`, `excerpt`, `tags`, `facts`) + Markdown |
| `content/plan.json` | редакционный план: рубрика, слаг, заголовок и дата каждой статьи |
| `src/site.js` | шаблоны страниц, парсер frontmatter и Markdown, генератор обложек (работает и в Node, и в браузере) |
| `src/style.css` | дизайн: светлая и тёмная тема, адаптивная сетка |
| `src/client.js` | поиск по архиву, переключатель темы, полоса тахометра — прогресс чтения |
| `build.mjs` | сборка |
| `dist/` | готовый многостраничный сайт: залейте папку на любой статический хостинг |
| `dist-artifact/index.html` | весь сайт одной страницей (hash-навигация) |

## Сборка

```bash
cd blog
node build.mjs                                   # Node 18+
SITE_URL=https://ваш-домен.ru node build.mjs     # абсолютные ссылки в sitemap.xml, rss.xml и canonical
```

Посмотреть локально: `python3 -m http.server -d dist 8080` и откройте http://localhost:8080.

## Рубрики

История · Устройство · Электро · Обслуживание · Вождение · Покупка · Автоспорт · Культура

## Как добавить статью

1. Создайте `content/articles/<slug>.md` с тем же frontmatter, что у существующих статей.
2. `category` — одна из: `history`, `tech`, `electric`, `service`, `driving`, `buying`, `motorsport`, `culture`.
3. Запустите `node build.mjs`: сборка проверит обязательные поля и сообщит об ошибках.

Обложки рисуются автоматически из слага статьи: у каждой рубрики свой мотив (шестерни, батарейные ячейки, дорога, клетчатый флаг и т. д.).
