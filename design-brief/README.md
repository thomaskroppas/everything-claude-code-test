# Бриф для Claude Design — журнал «Отсечка»

Всё, что нужно, чтобы Claude Design сделал полный тёмный премиальный дизайн сайта.

## Что в папке

| Файл | Зачем |
|---|---|
| `PROMPT.md` | Сам промпт: проект, стиль, дизайн-система (цвета, шрифты, сетка, компоненты), список из 10 экранов, требования к изображениям |
| `articles.md` | Настоящий контент всех 100 статей по рубрикам: номер, дата, время чтения, теги, лид, «паспорт темы» |
| `articles.json` | То же самое в машинном виде |
| `sample-article-porsche-911.md` | Полный текст статьи № 088 для экрана «Статья» |

## Как запустить

1. Откройте Claude Design (claude.ai → Design).
2. Скопируйте из `PROMPT.md` всё, что ниже горизонтальной линии, и вставьте в чат.
3. Приложите файлы `articles.md` и `sample-article-porsche-911.md`.
4. Отправьте. Если Claude Design начнёт задавать вопросы — отвечайте «на твой вкус, в рамках брифа».
5. Правьте результат комментариями на холсте, пока не понравится.

## Как вернуть результат

Пришлите в эту сессию **ссылку на готовый холст** (вида `https://claude.ai/artifact/…`). Я прочитаю дизайн и перенесу его в код сайта: шаблоны в `blog/src/site.js`, стили в `blog/src/style.css`, пересоберу все 112 страниц и обновлю опубликованную версию.

Если ссылкой поделиться нельзя — экспортируйте холст в HTML или PDF и приложите файл.
